# SCRIPT DE DEMO - 3 MINUTOS
## Práctica para la reunión con el director

**OBJETIVO:** Conseguir aprobación del presupuesto  
**TIEMPO:** 3 minutos de demo + 5-10 min de preguntas  
**ESTRATEGIA:** Mostrar, no explicar. Que vea el problema y la solución con sus propios ojos.

## 🎯 LENGUAJE CORPORAL Y TONOS

### AL MOSTRAR EL PROBLEMA:
- Tono: Frustración controlada
- Gesto: Negar con la cabeza
- Velocidad: Normal
- **Mensaje:** "Esto es un problema serio"

### AL MOSTRAR LA SOLUCIÓN:
- Tono: Entusiasmo contenido
- Gesto: Señalar la pantalla con el dedo
- Velocidad: Poco más rápido
- **Mensaje:** "Mirá qué fácil es"

### AL DAR LOS NÚMEROS:
- Tono: Serio, profesional
- Gesto: Mirar a los ojos
- Velocidad: Más lento (que procese)
- **Mensaje:** "Esto es matemática pura"

### AL PEDIR EL PRESUPUESTO:
- Tono: Confiado, no suplicante
- Gesto: Palmas abiertas
- Velocidad: Normal
- **Mensaje:** "Es un win-win"

## 🚫 ERRORES A EVITAR

1. ❌ **No empezar con "yo hice"** → Empezar con "tenemos un problema"
2. ❌ **No explicar la tecnología** → Mostrar resultados
3. ❌ **No mendigar** → Presentar como oportunidad de negocio
4. ❌ **No pedir disculpas** → "Perdón por molestarte" = debilidad
5. ❌ **No llenar silencios** → Las pausas son poderosas
6. ❌ **No aceptar menos de $250K** → Conocés tu valor
